# assets-src

원본 자료를 두는 곳. 포스터, 로고, 사진, 영상 썸네일, 음원.

* 포스터를 가장 먼저 올린다. 지시서(`docs/brief.md`)는 이 폴더에 포스터가 있으면 그것부터 본다.
* 깃허브 화면에서 올릴 때는 이 폴더에 들어가서 Add file, Upload files 순으로 누른다. 화면으로 올릴 수 있는 크기는 파일 하나에 25MB까지다.
